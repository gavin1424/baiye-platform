# XP-N160II 商家安裝說明

## 1. 裝紙

開啟印表機上蓋，放入 80mm 熱感應紙，留一小段紙在出紙口外後蓋緊。

## 2. 連接網路線

將 XP-N160II Ethernet 網路線連接到商家路由器。Android 手機必須連到同一台路由器的 Wi-Fi。

## 3. 查找 IP 與 Port

使用印表機自測頁、原廠網路設定工具或路由器裝置清單找到 IP，例如 `192.168.1.200`。

Port 必須以實機網路設定為準。App 內的 Port 可修改，不要因常見預設值而跳過確認。建議在路由器為印表機設定 DHCP reservation，避免 IP 變動。

## 4. App 輸入 IP

開啟「點餐靈」，使用現有商家帳號登入，前往「更多 → 印表機」，輸入：

- 名稱：XP-N160II Kitchen Printer
- IP Address：實機 IP
- Port：實機 Port
- 份數：1

## 5. 測試連線

點「測試連線」。出現 `Network reachable` 只代表手機能連到該 IP/Port，不代表印表機有紙、上蓋已關、切刀或印頭正常。

## 6. 測試列印

點「測試列印」。請用眼睛確認：

- 「點餐靈」與「連線測試成功」繁體中文正確
- 沒有 `????`、亂碼或空白中文
- 80mm 紙寬沒有裁字
- 列印後有切紙

如果沒有實體紙張，不能只因 App 顯示已送出就當作列印成功。

## 7. 開啟 Auto Print

測試紙完全正確後，開啟「自動出單」並儲存，允許 App 通知權限。手機會顯示「創百業出單服務運作中」常駐通知。

若列印紀錄顯示「可能已列印，請確認後補印」，請先找紙本，確定沒有印出才點「補印」。

## 本版尚待實機確認

XP-N160II 實機 Port、繁中 raster 列印、完整切紙、長單連續列印與 bidirectional status 能力尚需在商家現場驗證。本 App 不宣稱可讀取缺紙、上蓋開啟或切刀錯誤。
