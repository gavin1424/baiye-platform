美玲拼布｜LINE、AI 與線上預約

安裝方式：
1. 在 WordPress 後台前往「外掛 → 安裝外掛 → 上傳外掛」。
2. 上傳 meiling-wordpress-integration.zip。
3. 啟用外掛。

此外掛不修改主題核心，會：
- 載入 Production AI Chat Widget。
- Header 加入「LINE 詢問」。
- Footer 加入「加入 LINE 官方帳號」。
- 手機版加入固定「LINE 聯絡」按鈕。
- Contact 頁加入正式 QR Code 與加好友按鈕。
- 自動建立 /booking/ 線上預約頁。
- Courses 頁加入「立即預約課程／諮詢」。
- 預約頁提供服務、日期、真實時段、查詢、改期與取消。

所有 LINE 入口固定指向：https://lin.ee/SdFAst4
